# Code of conduct

Be kind and assume good faith. Disagree about the work, not the person.
Harassment, personal attacks and discrimination are not tolerated here, in
issues, pull requests or any other project space.

Maintainers may edit or remove contributions that break these rules and may
block repeat offenders. Report a problem privately through GitHub's
"Report content" option or by opening a private security advisory on the
repository.

This is a short summary in the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in full.
